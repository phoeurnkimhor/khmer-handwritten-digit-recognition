A deep learning-powered web application for recognizing hand-drawn Khmer digits. Features a FastAPI backend with a bidirectional GRU model and a modern Next.js frontend for real-time digit recognition.

## Features

- **Real-time Recognition**: Draw Khmer digits on canvas and get instant predictions
- **Deep Learning Model**: Bidirectional GRU with attention mechanism
- **Modern UI**: Responsive web interface with smooth drawing experience
- **RESTful API**: Clean API endpoints with interactive documentation
